# Архив бесед сообщества

**Больше 130 сохранённых бесед из чатов Хекслета** — разборы технологий, споры о процессах
и инструментах, слаконары с гостями.

Беседы живут в [вики репозитория](https://github.com/Hexlet/hexlet-slack-archive/wiki):
одна страница — один разговор, с датой в заголовке.

## Как помочь?

Правки и добавления приветствуются — беседы редактируются прямо в вики.

* Указывайте дату в заголовке беседы в формате *[yyyy MM dd]*: `[2016 01 12] Все об Erlang`.
